# RESEE

See Your Future 🚀

An AI-powered career platform that helps students and professionals with:

- Resume Analysis
- Mock Interviews
- Career Roadmaps
- Skill Gap Analysis
- AI Career Chat
- Document Intelligence

## Repository structure

The application lives entirely under [`website/`](./website) (Next.js App
Router, TypeScript, Supabase). Everything else at the repo root is
documentation and repository scaffolding:

- [`docs/`](./docs) — product, architecture, module, design, standards,
  ADR, and roadmap documentation. Start at [`docs/README.md`](./docs/README.md).
- [`templates/`](./templates) — reusable templates for proposals,
  decision records, meeting notes, and release notes.
- [`.github/`](./.github) — issue/PR templates, CI, CODEOWNERS,
  contributing guide.

## Local development

```
cd website
npm install
npm run dev
```

See [`website/README.md`](./website/README.md) for framework-specific
notes.
